## 📖 About The Project

**Discover Bogura Server** is the backend API of the Discover Bogura web application.

It is built with **Node.js, Express.js, MongoDB, and Firebase Admin SDK** and provides RESTful APIs for managing and retrieving information about Bogura district.

The backend handles data related to:

* 🏙️ Upazilas
* 👨‍🎓 Famous People
* 🏫 Schools & Colleges
* 🕌 Madrasas
* 🏥 Medical Institutions
* 👮 Police Stations
* 🚒 Fire Service Offices
* 🏛️ Government Institutions
* 🏞️ Tourist Attractions
* 🍲 Traditional Foods
* 🌊 Rivers
* 📍 Important Places

# ✨ Features

### 🔌 RESTful API

Provides REST APIs for communicating with the frontend application.

### 🗄️ MongoDB Database

MongoDB is used to store and manage district-related information.

### 🔐 Firebase Authentication

Firebase Admin SDK is used to verify Firebase ID tokens on protected routes.

### 🛡️ Protected Routes

Authenticated users can access protected API endpoints using Firebase authentication tokens.

### 📍 District Information

The server provides information about different locations and institutions throughout Bogura.

### 🏙️ Upazila-Based Data

Information can be organized and retrieved according to Bogura's Upazilas.

### 🔄 Client-Server Communication

The backend communicates with the React frontend through REST APIs.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/anamulhaque378732/discover-bogura-server.git
```

## 2. Go to the Server Directory

```bash
cd discover-bogura-server
```

## 3. Install Dependencies

```bash

```

---

# 🔐 Environment Variables

Create a `.env` file in the root directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string

FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
FIREBASE_PRIVATE_KEY=your_firebase_private_key
```

> ⚠️ Never upload `.env` or Firebase private credentials to GitHub.

# 🔐 Firebase Authentication

The backend uses **Firebase Admin SDK** to verify Firebase ID tokens.

The authentication flow:

```text
User Login
    ↓
Firebase Authentication
    ↓
Firebase ID Token
    ↓
React Client
    ↓
Authorization Header
    ↓
Express Backend
    ↓
Firebase Admin SDK
    ↓
Token Verification
    ↓
Protected API
```

Example authorization header:

```text
Authorization: Bearer <firebase-id-token>
```

# 🚀 Deployment

The backend is deployed as a **Node.js Web Service on Render**.

### Build Command

```bash
npm install
```

### Start Command

```bash
npm start
```

The server uses the Render-provided port:

```js
const port = process.env.PORT || 5000;

app.listen(port, () => {
  console.log(`Server running on port ${port}`);
});
```
